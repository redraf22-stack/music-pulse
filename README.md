# 🎵 MusicPulse

> ⚠️ **ВНИМАНИЕ**: Это **не финальный продукт**, а активная разработка. Возможны баги, недоделанные функции и изменения API. Используйте на свой страх и риск.

Приложение для **синхронного прослушивания музыки** в реальном времени с друзьями. Создаёшь комнату — делишься 5-значным кодом — все слушают один и тот же трек одновременно.

## ✨ Возможности

- 🎵 **Синхронный плеер** — музыка играет одновременно у всех участников
- 🔍 **Поиск треков** через Deezer API (30-сек превью)
- 💾 **Локальная музыка** — добавь папку со своими MP3/FLAC
- 🔗 **Треки по URL** — вставь ссылку на любой аудиофайл
- 🎤 **Голосовой чат** через WebRTC (PeerJS)
- 📹 **Видеосвязь и трансляция экрана**
- 🎼 **Плейлисты** — создавай и делись подборками
- ↩️ **История** — 10 последних треков, можно откатить назад
- 👥 **Роли**: Админ, Модератор, VIP
- 📡 **LAN обнаружение** — видишь комнаты в локальной сети
- 🗳️ **Голосования** за следующий трек
- ⌨️ **Глобальные хоткеи** — PTT (удержание), мьют и глушение работают поверх любых приложений и игр; кнопки мыши «назад/вперёд» тоже
- 🎵 **Системные медиа-клавиши** — Play/Pause, Next, Prev управляют комнатой, пока ты в ней; **F8/F9/F7 по умолчанию** (переназначаются в настройках — спасает, если драйвер клавиатуры съедает медиакнопки, как ASUS Armoury Crate)
- 📌 **Открепляемое окно чата** — поверх окна плеера
- ↕️ **Drag & drop** — перетащи картинку/видео/аудио прямо в чат
- 🌍 **Два языка**: Русский и English
- 🔁 **Автообновление** — тихо подтягивает новую версию с GitHub
- 🔐 **Самоподписанный HTTPS** для работы вне LAN

## 🚀 Установка

### Для пользователей (Windows)
1. Скачай последний `.exe` из [Releases](../../releases)
2. Запусти, введи ник и создай комнату
3. Поделись 5-значным кодом с друзьями

> 🛡 **Windows SmartScreen** ругается «Неизданный издатель» — это нормально, приложение не подписано коммерческим сертификатом. Нажми **«Подробнее» → «Всё равно запустить»**.

### Для разработчиков
```bash
git clone https://github.com/redraf22-stack/music-pulse.git
cd music-pulse
npm install
npm start
```

## 📦 Сборка и релиз

```bash
npm run release
```

Собирает инсталлятор (`MusicPulse Setup X.Y.Z.exe`) и portable-версию, затем публикует их на GitHub Releases (нужен `GH_TOKEN`). Клиенты подтягивают обновление автоматически.

## 🆕 Что нового в 2.0.21

- ⚙️ **Единое окно настроек** — слева панель-навигация (как в Unity), справа контент: Общие / Устройства / Музыка / Горячие клавиши / Эквалайзер / Плейлисты; секция **«Настройки комнаты»** (эквалайзер комнаты + техчасть с кулдаунами) — только у админа/мода
- 🔊 **Мастер-громкость: шкала −200%…+100%** — **−200% = тишина**, **0% = обычная громкость**, **+100% = усиление ×3**; между 0 и 100% — мягкая лог-кривая для тонкой настройки; старые значения мигрируют автоматически без изменения громкости
- 🐛 **Фикс громкости**: после открытия эквалайзер больше не делает музыку тише (элемент и WebAudio-gain больше не умножаются друг на друга)
- 🎛 **Эквалайзер: личный или комнатный** — переключатель источника: слушатели идут за комнатным EQ админа, но могут включить свой (в обход комнатного); правит комнатный только админ/мод, отдельный вход «Эквалайзер комнаты» — в секции настроек комнаты; вкладка комнатного EQ правит **только** комнатный EQ и больше не переключает слушателя с личного источника; переключатель виден в обычной вкладке при **любом** источнике (починен баг: при «Комната» по умолчанию его там не было — показывалась комнатная подсказка)
- 🎨 **Единый дизайн вкладок настроек** — все вкладки свёрстаны одинаково: **контент — одна колонка 480px по центру панели** (вкладки больше не растягиваются под текст «в одну линию» — все одного размера), карточки-строки одного стиля; вкладка «Технические» переделана под общий вид (больше не копия сайдбар-панели); у активного пункта навигации убрана «марка» слева — только подсветка, как в CS
- 📋 **Общие и Устройства — одна вкладка** — раньше «Общие» были только языком, а «Устройства» дублировали язык + устройства; теперь в комнате и на старте всё на одной вкладке «Общие»
- 🪟 **Все настройки — одним окном** — «Настройки песен» (поиск/фильтры/просмотр) переехали из отдельного окошка 520px в хаб вкладкой «Настройки песен»; кнопка ⚙ рядом с поиском открывает хаб сразу на этой вкладке; внутри больше нет дублей «Моя музыка»/«Личные плейлисты» — они уже в панели навигации
- 📐 **Компактные горячие клавиши** — строки, подсказка и футер уплотнены — вкладка больше не «длинная»
- 🐛 **Фикс окна настроек**: контент внутри вкладок больше не «голеет» (стили модалок привязаны к их #id-предкам — теперь в панель переезжает вся модалка целиком), вкладки при переключении туда-обратно не опустошаются, action-вкладки (плейлисты/моя музыка) не ломают панель
- 🎨 **Единый фон настроек** — панель контента теперь одного тёмного фона приложения на всех вкладках (раньше фон «плавал» от вкладки к вкладке); кнопка «⚡ Технические настройки» в левом сайдбаре убрана (дублировала вкладку хаба)
- 🧹 **Горячие клавиши без эмодзи** — убран дубль иконки в строках и «синие» медиа-эмодзи (⏯️⏭️⏮️); подпись теперь чистый текст
- 🐛 **Фикс старта трека**: новая песня теперь начинается строго с начала — позиция считается от момента получения команды, а не от момента загрузки файла (файл дольше 400 мс больше не «перепрыгивал» вступление); после фактического старта звука админ/мод пересылают точную позицию — убирает «подлагивание» из-за разного времени загрузки у слушателей
- 🌍 **Фикс перевода**: «🎶 В очереди» теперь переводится на английский
- 🧪 **Тесты: 44+ проверка** — хоткеи 16 + эквалайзер 8 + громкость 7 + окно настроек (2 сценария) + сервер 11
