# 🎵 MusicPulse

Синхронное прослушивание музыки с друзьями по локальной сети — как LAN-миры в Minecraft.

## Возможности
- 🏠 Комнаты с 5-значным кодом и кнопкой 🚪 выхода
- 📡 Видимость комнаты в локальной сети (тумблер у админа)
- 🎙️ Войс-чат, 📷 видео, 📺 трансляция экрана
- 💬 Чат с эмодзи и медиафайлами
- 🔀 Режим рандома из своей музыки
- 🔍 Поиск Deezer (превью 30 сек) + свои треки через `#full`
- 👑️⭐ Роли админ/мод/VIP, кики и баны
- 📁 Выбор папки с музыкой в настройках ⚙️

## Как играть вдвоём
1. Оба в одной сети (WiFi).
2. Хост: «Создать комнату» → получает код.
3. Друг: видит хоста в списке «Комнаты в локальной сети»
   или вводит `IP_ХОСТА:КОД` в прямом подключении.

## Установка
- Скачай `MusicPulse 1.1.0.exe` в **Releases** и запусти.
- Свою музыку положи в `%APPDATA%\MusicPulse\music`
  (или выбери папку в настройках ⚙️).

## Для разработчика
npm install
npm start        # запуск приложения
npm run server   # только сервер (веб-версия в браузере)
npm run build    # сборка exe

## Стек
Electron + Express + Socket.IO + PeerJS + Deezer API
